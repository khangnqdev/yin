Quy Chuẩn Soạn Thảo & Mẫu Prompt AI

Xuất mẫu quy định hoặc sao chép Prompt để đưa cho AI ngoài (ChatGPT, Claude, Gemini...)

Quy trình nạp bài viết từ AI vào Yin:

  1. Bước 1: Tải file .md mẫu hoặc sao chép Prompt AI

    Nhận cấu trúc Markdown Frontmatter chuẩn hóa (tiêu đề, slug, tóm tắt, từ khóa, gợi ý ảnh bìa).

  2. Bước 2: AI tạo bài viết và xuất file .md

    Dán prompt cho ChatGPT/Claude để AI viết nội dung có H2, H3, bảng so sánh và phân đoạn rõ ràng.

  3. Bước 3: Bấm nút "Nhập file .md"

    Hệ thống tự động đọc và mở ngay bài viết trong trình soạn thảo, sẵn sàng xuất bản chỉ sau vài giây.
