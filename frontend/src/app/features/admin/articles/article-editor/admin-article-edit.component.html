Quy Chuẩn Soạn Thảo & Mẫu File .MD

Xuất mẫu quy định hoặc sao chép Prompt để đưa cho AI ngoài (ChatGPT, Claude, Gemini, DeepSeek...)

Quy trình biên soạn và nạp bài viết:

  1. Bước 1: Tải mẫu hoặc sao chép Prompt AI

    Tải file .md mẫu về máy hoặc sao chép Prompt AI đã được tối ưu hóa tiêu chuẩn SEO & CORE-EEAT.

  2. Bước 2: Yêu cầu AI soạn bài & xuất file .md

    Gửi nội dung cần viết cho AI (ChatGPT, Claude...) kèm quy chuẩn mẫu. Nhắc AI xuất ra file Markdown kèm cấu trúc Frontmatter (tiêu đề, slug, tóm tắt, danh mục, gợi ý ảnh bìa).

  3. Bước 3: Nhập file .md vào website

    Bấm nút "Nhập File .MD" trên thanh công cụ hoặc kéo thả file .md trực tiếp vào khung soạn thảo. Hệ thống sẽ tự động điền toàn bộ dữ liệu và hiển thị bản xem trước.

  4. Bước 4: Tùy biến hình ảnh & định dạng

    Tải ảnh bìa theo gợi ý prompt, chèn thêm hình ảnh minh họa bằng nút hình ảnh hoặc kéo thả ảnh vào vị trí mong muốn trong bài viết.

Cấu trúc mẫu Frontmatter (.md):
---
title: "Tiêu Đề Bài Viết Hấp Dẫn Dưới 65 Ký Tự Chuẩn SEO"
slug: "tieu-de-bai-viet-chuan-seo"
excerpt: "Đoạn mô tả ngắn tóm tắt giá trị bài viết từ 120-160 ký tự, giúp tối ưu thẻ Meta Description."
category: "Công Nghệ"
tags: ["SEO", "Công Nghệ", "Hướng Dẫn"]
cover_image_prompt: "Minimalist modern 3D illustration of digital technology..."
---
