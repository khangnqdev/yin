Quy chuẩn & Template bài viết (.md)

Dành cho quy trình tạo bài với AI bên ngoài (ChatGPT, Claude, Gemini...). Xuất file quy chuẩn để AI soạn bài và xuất file .md nạp trực tiếp vào web.

1
Tải file format hoặc sao chép Prompt:

Gửi file quy định hoặc dán prompt vào cửa sổ chat với AI (ChatGPT, Claude, v.v.).

2
Soạn bài cùng AI:

Yêu cầu AI viết theo chủ đề mong muốn và xuất ra toàn bộ bài trong MỘT FILE Markdown (.md) chuẩn Frontmatter.

3
Nhập vào trình soạn thảo & Xem trước:

Vào trang biên tập bài viết, bấm "Nhập file .md" hoặc kéo thả file vào editor. Web sẽ tự động phân tích tiêu đề, slug, danh mục, từ khóa và hiển thị xem trước trước khi áp dụng.
